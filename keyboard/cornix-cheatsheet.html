L0 押下F13F18
L3 回転音量 − / +ホイール ↑ / ↓
L3 押下ミュート中クリック
L4 回転Z / C（90° 回転）▽
  • L1 / L2 と、L4 の押下・右ノブ回転は透過。L0 と同じ挙動。L5 は透過で L4 と同じ挙動（左ノブ回転は Z / C）。

コンボ

Q + WTab
O + P-

マクロ

M0Esc → 英数（左手上段最外）

タップ / ホールド設定

  • Permissive Hold: ON
  • Hold On Other Key Press: OFF
  • Flow Tap: OFF
  • Chordal Hold: ON（純正ファームでは no-op）
  • HRM は使わない。修飾は単独キー（左: ⌃ ⇧ ⌥ ⌘ と親指 ⌘、右: ⇧）。設定はレイヤーキー（英数 / かな）のタップ判定に効く
  • L4 GAME は右手マウス前提
  • L4 の WASD 位置が矢印キーなのは、コンボ Q + W → Tab がレイヤーを問わず発火するため（Q と W の同時押しで誤爆する）
  • L6–L9 は未使用。通常キーは KC_NO だが、ノブ（押下 = ミュート / 中クリック、回転 = 音量・ホイール）だけ既定値が残っている
